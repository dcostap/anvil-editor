# Agent icons

Pi's official mark comes from <https://pi.dev/favicon.svg>, retrieved on 2026-10-22.
These files keep its paths and light/dark colors unchanged.
They use fixed fills because the SVG loader does not select CSS media queries.

Pi's source: <https://github.com/earendil-works/pi>.
OpenAI's Blossom comes from its [official logo download](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip).
The SVG viewBox removes outer blank space. The paths and colors remain unchanged.

Claude's starburst comes from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/claude.svg), under [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
Its paths remain unchanged. It uses Claude's orange on both light and dark backgrounds.
Both sources were retrieved on 2026-10-22.

These marks identify Pi and the selected model's family or maker. They do not imply endorsement of Anvil.
